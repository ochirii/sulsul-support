# 술술 — 말하면 글이 된다

아이폰에서 말한 내용을 글로 옮기고, 필요하면 AI로 다듬는 받아쓰기 앱입니다.

## 처음 사용하기

1. 술술 앱을 열고 마이크와 음성 인식 권한을 허용합니다.
2. 앱의 **받아쓰기**를 누르고 말한 뒤 **끝내기**를 누릅니다. 결과는 기록에 저장되고 클립보드에 복사됩니다.
3. 다른 앱에서 쓰려면 iPhone 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가에서 **술술**을 추가합니다.
4. 술술 키보드의 **전체 접근 허용**을 켭니다. 앱과 키보드가 받아쓰기 요청과 결과를 교환하는 데 필요합니다.
5. 술술 앱에서 **세션 시작**을 누른 뒤 사용할 앱으로 돌아갑니다. 지구본 버튼으로 술술 키보드를 선택하고 마이크를 눌러 받아씁니다.
6. 세션이 끝나면 다시 술술 앱에서 시작합니다. **세션 끝내기**로 언제든 마이크를 끌 수 있습니다.

## AI 정리는 선택 사항입니다

기본 받아쓰기는 API 키 없이 기기 내 음성 인식을 사용합니다. 기기에 한국어 인식 모델이 설치되어 있어야 합니다. 모델이 준비되지 않았다면 iPhone 설정에서 한국어 받아쓰기를 활성화하고 네트워크에 연결해 모델을 준비한 뒤 다시 시도하세요.

설정에서 제공자별 전송에 동의하고 본인의 API 키를 넣으면 Claude 또는 GPT로 문장을 다듬을 수 있습니다. 외부 API 이용료는 해당 제공자와의 계약에 따릅니다. 앱 내 결제와 구독은 없습니다.

- **자동**: 짧은 말은 그대로, 긴 말은 내용에 맞게 정리합니다.
- **충실**: 말한 낱말과 말투를 최대한 유지합니다.
- **의도**: 군더더기를 줄이고 문장과 목록을 정돈합니다.
- OpenAI 음성 인식은 음성 전송에 따로 동의한 뒤 선택해야 합니다.

## 자주 묻는 질문

**마이크 표시가 계속 켜져 있어요.**
세션이 유지되는 동안 표시됩니다. 받아쓰기 버튼을 누르지 않은 동안의 소리는 저장하거나 전송하지 않습니다. 술술 앱에서 세션을 끝내면 표시가 꺼집니다.

**전체 접근을 켜지 않아도 쓸 수 있나요?**
키보드의 영문·숫자·기호 입력, 삭제, 공백, 줄바꿈과 다음 키보드 전환은 가능합니다. 음성 받아쓰기 결과 교환에는 전체 접근이 필요합니다.

**키보드가 앱을 열어 주지 않아요.**
먼저 술술 앱에서 세션을 시작한 뒤 돌아오세요. 키보드가 다른 앱을 자동으로 실행하지 않습니다.

**AI 정리가 작동하지 않아요.**
설정에서 해당 제공자의 텍스트 전송 동의, API 키, 모델 및 연결 테스트 결과를 확인하세요. 외부 서비스 오류 시 인식 원문을 사용합니다.

**기록과 키는 어떻게 삭제하나요?**
기록 화면에서 개별 또는 전체 삭제할 수 있습니다. 설정에서 API 키 입력란을 비우면 기기의 Keychain에서 삭제됩니다. 외부 제공자에 이미 전송된 데이터는 해당 제공자의 삭제 절차를 따릅니다.
